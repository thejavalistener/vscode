# Resumen de hotkeys útiles

## Editor

| Atajo                        | Acción                          |
|------------------------------|---------------------------------|
| `Ctrl` + `+`                 | Aumentar zoom del editor        |
| `Ctrl` + `-`                 | Disminuir zoom del editor       |
| `Ctrl` + `0`                 | Restablecer zoom                |
| `Ctrl` + `D`                 | Borrar línea actual             |
| `Ctrl` + `Shift` + `Y`       | Copia y pega la línea actual    |
| `Alt` + `Ctrl` + `Up`/`Down` | Cursores múltiples              |
| `Alt` + `1`                  | Abrir el explorador de archivos |
| `Alt` + `2`                  | Abrir terminal externa          |

## Paneles

| Atajo                           | Acción                                                          |
|---------------------------------|-----------------------------------------------------------------|
| `Ctrl` + `M`                    | Ocultar/mostrar panel lateral                                   |
| `Ctrl` + `SHIFT` + `M`          | Ocultar/mostrar panel inferior                                  |
| `Alt` + `Shift` + `M`           | Ocultar/mostrar la barra lateral (Activity Bar)                 |
| `Alt` + `X`                     | Hacer foco a la terminal integrada                              |
| `Ctrl` + `Alt` + `X`            | Abrir una nueva terminal posicionada en la carpeta del proyecto |
| `Ctrl` + `Alt` + `shift` +`X`   | Abrir una nueva terminal posicionada en la carpeta del archivo  |
| `Ctrl` + `R`                    | Cambiar de Workspace                                            |


## Código, compilar y debuggear

| Atajo                   | Acción                                                   |
|-------------------------|----------------------------------------------------------|
| `Ctrl` + `Shift` + `B`  | Compilar                                                 |
| `Ctrl` + `F11`          | Compilar y ejecutar                                      |
| `Ctrl` + `Shift` + `F`  | Formatear el código                                      |
| `Alt` + `Shift` + `R`   | Renombrar símbolo o variable                             |
| `Ctrl` + `7`            | Comentar código seleccionado                             |
| `Ctrl` + `Shift` + `7`  | Descomentar código seleccionado                          |
| `Ctrl` + `Shift` + `J`  | Reload Window (para recononocer el package root de Java) |
| `F11`                   | Comenzar a debuggear                                     |
| `F12`                   | Ídem. F11                                                |
| `F6`                    | Step over                                                |
| `F5`                    | Step into                                                |
| `F8`                    | Continuar hasta el siguiente breakpoint                  |
| `F9`                    | Continuar hasta el cursor                                |
| `Ctrl` + `F2`           | Detener el debugger                                      |

## Project explorer

| Atajo                 | Acción                                  |
|-----------------------|-----------------------------------------|
| `Alt` + `Shift` + `F` | Agregar carpeta al workspace            |
